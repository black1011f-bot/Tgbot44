# BOUNTY HUB — Mini App

Адаптивная стартовая страница BOUNTY HUB для Telegram Mini App, браузера на телефоне и ПК.

На главной только две кнопки:
- Windows — пока сообщает, что ПК-сборка в разработке.
- Android — показывает, что мобильная версия пока не выпускается.

В проекте используется иллюстрация взрослой аниме-эльфийки. Позже её можно заменить на утверждённый авторский арт BOUNTY HUB.

## GitHub Pages
Публикация настроена workflow-ом из папки `.github/workflows/deploy-pages.yml`. Для первого запуска открой Settings → Pages и проверь, что Source установлен на **GitHub Actions**.
