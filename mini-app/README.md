# BOUNTY GAMING website

Современный адаптивный сайт BOUNTY GAMING / BOUNTY HUB.

## Файлы
- `index.html` — главная, арт, режимы, галерея и Telegram-ссылки.
- `styles.css` — монохромный интерфейс, адаптивная сетка, анимации и закреплённый фон.
- `script.js` — мобильная навигация и анимация появления секций.
- `configurations.html` — предварительные системные ориентиры.
- `privacy.html` — стартовый черновик политики конфиденциальности.

## Публикация
GitHub → Settings → Pages → Deploy from a branch → main → /(root).

## Supabase
В этой версии сайт не подключает Supabase напрямую: для безопасной интеграции сначала нужно определить реальные таблицы, методы авторизации и разрешённые операции. Публичный anon/publishable key допустим только при правильно настроенных RLS policies. Никогда не помещайте service_role key в браузерный код.

Перед подключением заполните URL проекта и публичный ключ в отдельном клиентском модуле, проверьте RLS для каждой таблицы и протестируйте доступ обычного пользователя. Политика конфиденциальности пока является черновиком и требует сверки с фактической конфигурацией.

## Важно
Системные требования являются предварительными оценками, а не проверенными характеристиками выпущенной игры. PC — первый этап, Android — последующий.
