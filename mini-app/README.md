# NEON LEGENDS Mini App

Responsive landing page for the NEON LEGENDS Telegram Mini App.

## Local preview
Open `index.html` in a browser.

## Publish with GitHub Pages
In the repository settings, open **Pages**, select **Deploy from a branch**, choose `main` and folder `/mini-app` (or publish the repository root if the Pages UI does not offer a subfolder). After publishing, the page will be available at the GitHub Pages URL.

## Telegram Mini App
After publishing, set the bot's menu button / Web App button URL to the published HTTPS URL. The page already loads Telegram Web Apps SDK and adapts to Telegram's viewport.

## Downloads
Windows and Android buttons intentionally show a "version is being prepared" message until actual installer/APK URLs are configured. Do not link placeholder files.
