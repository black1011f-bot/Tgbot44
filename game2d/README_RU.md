# BOUNTY HUB 2D

Отдельный Godot 4 проект внутри репозитория Tgbot44. Файлы Telegram-бота и Mini App не изменяются.

## Открытие проекта
1. Установи Godot 4.x.
2. В Project Manager нажми **Import**.
3. Выбери файл `game2d/project.godot`.
4. Открой проект и нажми F6/F5 (запуск главной сцены/проекта).

## Текущий прототип
- Адаптивная 2D оболочка 1280×720.
- Главное меню и выбор четырёх режимов.
- Экран тестовой комнаты с названием и количеством игроков.
- Совместимая базовая конфигурация рендерера для Windows и Android.

## План разработки
1. Полноценные игровые сцены и правила Манчкина, Бункера, Шпиона и Крокодила.
2. Анимации, карты, игровые предметы и эффекты.
3. Сетевые комнаты, аккаунты и синхронизация состояния.
4. Экспорт Windows и Android, тестирование на реальных устройствах.

**Важно:** текущая версия — стартовый интерфейсный прототип. Онлайн-мультиплеер и полные правила игр ещё не реализованы.
