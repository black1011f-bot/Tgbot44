# Neon Hearts: After Dark — Android

Отдельная Android-игра, не связанная со сборкой BOUNTY HUB для Windows.

## Что есть в первой версии
- возрастное подтверждение 18+;
- три совершеннолетние героини (22–24 года);
- три отдельных маршрута по четыре сцены;
- выборы в диалогах и очки близости;
- два варианта финала для каждого маршрута;
- автосохранение прогресса на устройстве;
- автономная работа без интернета.

Романтические и флирт-сцены описаны текстом; графических сексуальных сцен нет.

## Сборка APK
Проект использует Android Gradle Plugin 8.7.3 и JDK 17.
В GitHub Actions запускается workflow **Build Neon Hearts Android APK**.
Результат первой тестовой сборки — debug APK, который можно установить вручную на Android.

## Папки
- `app/src/main/java` — Android-оболочка на Kotlin.
- `app/src/main/assets` — локальный интерфейс и логика визуальной новеллы.
